Deep Dive into Data Analysis with R

深入浅出R语言数据分析

Description

Covers data analysis methods and common models, then works through case studies in R: data acquisition and web scraping, preprocessing and exploration, survival analysis, principal component analysis, linear and logistic regression, clustering, association rules, random forests, support vector machines, neural networks, text mining and social network analysis. Written for beginner and advanced R users and for data science practitioners.
