PersonalSpace

A native macOS personal digital space

A local-first personal library: read-only access to folders you authorize, search and preview, and reminders for what needs doing.

GitHub ↗

What it is

A native macOS app connecting documents, personal objects, orders, contracts, warranties and subscriptions. Authorized folders are read-only; imported files are copied into a local library. Search, preview, fact review, action reminders and backup/restore work alongside an application-wide assistant using local Ollama.

Features

  • Count a folder before confirming indexing; track subsequent file changes
  • Name search, explicitly permitted full-text search and system previews
  • Personal objects, document links, managed copies and quick import
  • Review facts for orders, contracts, warranties and subscriptions; manage multiple actions and local reminders
  • Local Ollama assistant for finding documents, preparing matters and native operations
  • Sensitive-document protection, backup/restore and retained previous libraries
