A local-first personal library: read-only access to folders you authorize, search and preview, and reminders for what needs doing.

About

A native macOS app with no server, account or online API. Scanning is read-only, managed copies are copies rather than moves, and there is no way to delete source files. Manual workflows keep working when no model is available. Milestones M1–M8 are implemented locally.

Features

  • Native file library with persistent folder authorization
  • Search and system preview
  • Personal objects, links and managed copies
  • Four kinds of matters with on-demand recognition, fact checking, to-dos and local system reminders
  • Sensitive markers, backup and restore, quick capture

Note

This is currently a local, ad hoc signed development build. It has not been signed with a Developer ID or notarized.
