What it is

Each design system lives in a single DESIGN.md: colors, type, radii, spacing and components. Lookbook renders the same sample page from those tokens, so you can see what Stripe, Linear or Notion feel like without reading the spec.

The problem

A design system is usually just a document: colors, type, radii and components described in prose. It is hard to see what it feels like in use, and harder still to compare a few of them. Lookbook renders those specs as pages, then turns them into formats you can copy into a project.

Where to use it

  • Hand it to an AI coding assistant such as Claude, Cursor or v0 and have it build interfaces in the chosen style
  • Drop the CSS variables or Tailwind config into your own project
  • Import into Figma's Tokens Studio (W3C Design Tokens JSON)
  • Keep DESIGN.md in the project root so your coding assistant can always refer to it

Design and technology

Data
Each design system is one DESIGN.md; categories and summaries live in CATALOG.md, which drives the cards and filters.
Rendering
One sample landing page rendered from each set of design tokens, so the systems are actually comparable.
Front end
Vite and plain JavaScript, output as a static site.
Export
Formats are bundled into a .zip in the browser, with no backend.
Quality
Automated tests cover data parsing, every page render, export formats and text contrast; GitHub Actions deploys on push to main.
