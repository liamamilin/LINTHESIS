What it is

The main collection is organized around artifact-making tasks. Each task explains the required file, how to open it and how to assess completion. Recorded runs distinguish success, failure and partial verification and include inspectable outputs. Short questions remain as a warm-up collection.

Features

  • Browse and search by output: animation, 3D scene, game, app and more
  • Full task prompts, file formats, opening instructions and acceptance criteria
  • Run records link to actual outputs and state execution conditions and verification status
  • Referenced and original tasks identify their sources; short questions have their own collection

Note

Displayed runs include Cursor assistance and tool use. They are not a ranking from blind tests of bare model APIs.
