Personal studio of 米霖 / Liam: software, books, writing and experiments.

**Site:** https://liamamilin.github.io/LINTHESIS/ (中文) · https://liamamilin.github.io/LINTHESIS/en/ (English)
**GitHub:** https://github.com/liamamilin · **Contact:** lin.mi.official@gmail.com

This repository is the source of the site: a static site generated by `build.py` from JSON in `data/`, served by GitHub Pages. Maintenance notes are in [MAINTAINING.md](MAINTAINING.md).

```bash
python3 build.py   # regenerate zh pages at the root and en pages under en/
python3 check.py   # zh/en parity, internal links, assets, link kinds
```
