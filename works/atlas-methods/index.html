Atlas Methods

可回查来源的 Skill 资料库

从真实 GitHub Skills 整理具体做法，按领域浏览摘要，并回查固定版本的原始来源。

已发布 已发布，可以直接使用。

访问网站 ↗GitHub ↗

这是什么

从已有 Skill 材料出发，保存具体做法、适用条件和重要限制，再逐步整理领域。公开资料库提供分类、搜索与来源筛选，方便发现方法、比较不同来源，并回到原文继续判断。

核心功能

  • 按工程、专业、创作与办公等领域浏览
  • 搜索 Skill，并按专题、来源仓库与排序方式筛选
  • 查看公开整理摘要与多个来源的合并记录
  • 回查 GitHub 固定版本，保留来源与转换记录

说明

资料整理与结构检查不等于逐条执行验证，使用时仍需核对原文与适用条件。
