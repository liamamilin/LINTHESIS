用自然语言建立关注，定期直接采集，给出带原始链接的事件。

介绍

从自然语言建立关注，到发现并试读信息源、定期采集、基线与去重，最后给出带原始链接的事件。无需任何 API Key。新建的关注只记录基线，之后出现的新内容才会提醒。

核心功能

  • 四种采集：GitHub Releases、GitHub 仓库发现、RSS / Atom、静态 HTML
  • 来源试读与确认，Feed 自动发现，CSS 选择器预览
  • 事件唯一键去重，ETag / 304，限流与网络错误可追踪
  • 菜单栏、系统通知、进程内定时检查与唤醒补查
  • 12 项自动化测试通过
