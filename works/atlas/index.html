Application Atlas

以场景寻找真实项目

从软件类型和具体用途出发，寻找真实开源项目，查看能力、适用条件与来源。

GitHub ↗

这是什么

沿软件类型、应用场景和真实项目建立资料之间的联系。可以浏览类型、搜索项目、查看适用条件与许可证状态、收藏和回查来源；资料任务用于记录新增研究与更新建议。

核心功能

  • 按软件类型、场景和具体用途发现项目
  • 项目卡片标明来源、许可证状态、适用条件与待补资料
  • 搜索、筛选、收藏与来源回查
  • 资料任务保留运行进度、更新建议与恢复入口

技术与平台

平台
Web · 本地 API
技术
