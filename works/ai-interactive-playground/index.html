现代 AI 原理互动科普馆

亲手理解模型与智能体

用滑块、按钮和小游戏，直观探索大模型、训练、推理、RAG 与智能体的工作方式。

访问网站 ↗GitHub ↗

这是什么

一组在浏览器中运行的 AI 原理教学模拟。通过概率转盘、注意力聚光灯、显存调度、检索与权限闸门等互动场景，把抽象机制变成可以操作和观察的过程；可按主题搜索、连续试玩并保存探索进度。

核心功能

  • 16 个主题、48 个互动玩具，覆盖模型、训练、微调、推理及 Agent Harness
  • 通过按钮、滑块和可视化观察参数、选择与运行结果之间的关系
  • 扩展到 Token、RAG、安全、MoE、MCP、多智能体、多模态、记忆与评测
  • 主题筛选与搜索，在站内直接试玩并切换上一项、下一项
  • 本地保存探索进度；教学演示无需配置模型 API
